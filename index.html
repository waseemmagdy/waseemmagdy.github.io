llms.txt for the five blogs

Static index files for the English and French blogs. Each file lists the blog name, its public address, observed topics, real 2026 article links and the sitemap link.

  • llms.txt — network index
  • llms-worldpulse.txt — WorldPulse News
  • llms-wealthstream.txt — WealthStream
  • llms-healthyliving.txt — Healthy Living
  • llms-eduspark.txt — EduSpark Academy
  • llms-flashpoint.txt — Flashpoint

Reference format: https://<user>.github.io/llms.txt for the user site, or https://<user>.github.io/<repo>/llms.txt for a project site.

Static files only. No tracking, scripts or third-party assets.
